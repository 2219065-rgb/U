# منصة AR on QR لكفرات الهاتف — نموذج MVP

نموذج عملي خفيف ومجاني الاستضافة (يعمل مباشرة على **GitHub Pages** بشهادة HTTPS تلقائية) لتشغيل تجربة واقع معزز (WebAR) عبر مسح رمز QR مطبوع على كفر الهاتف بالطباعة الحرارية، من دون الحاجة لتحميل أي تطبيق.

## ماذا يتضمن هذا المشروع؟
- `index.html` + `js/app.js` + `css/style.css`: صفحة تجربة الواقع المعزز الديناميكية باللغة العربية (RTL)؛ تقرأ معرّف الطلب من الرابط (مثل `?id=demo-01` أو `?id=order-101`) وتعرض الفيديو والأزرار الخاصة بكل زبون فوق تصميم الكفر.
- `qr-generator.html`: أداة جاهزة لك لتوليد رموز QR عالية الدقة (PNG / SVG) جاهزة للطباعة الحرارية، مع توليد كود الإعداد الخاص بكل طلب.
- `data/cases.json`: قاعدة البيانات الديناميكية؛ يمكنك تعديل الفيديو أو الروابط لأي كفر حتى **بعد طباعته وتسليمه للزبون** دون تغيير رمز الـ QR.
- `assets/demo-target.png` و`assets/demo-video.mp4`: صورة هدف عالية التباين وفيديو تجريبي خفيف للاختبار الفوري.

## خطوات التشغيل والنشر على GitHub Pages (في 3 دقائق)

### 1. توليد ملف التتبع `targets.mind` (لأول مرة أو عند إضافة تصميم كفر جديد)
1. افتح محوّل MindAR الرسمي في متصفحك: `https://hiukim.github.io/mind-ar-js-doc/tools/compile`
2. ارفع صورة التصميم `assets/demo-target.png` (أو تصميم كفرك الخاص) واضغط **Start**.
3. اضغط **Download compiled** واحفظ الملف باسم `targets.mind` داخل مجلد `assets/`.

### 2. الرفع على GitHub وتفعيل HTTPS مجاناً
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub (مثلاً `ar-case-mvp`).
2. ارفع جميع ملفات هذا المجلد إلى المستودع.
3. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. خلال دقيقة سيصبح موقعك جاهزاً على رابط آمن مثل:
   `https://<username>.github.io/ar-case-mvp/?id=demo-01`
   *(ويمكنك ربطه بنطاق `.me` أو `.tech` المجاني من حزمة GitHub Student Developer Pack).*

### 3. تجربة الهاتف
- افتح الرابط على هاتفك (Safari للآيفون أو Chrome للأندرويد)، أو امسح رمز الـ QR المولّد من `qr-generator.html`.
- وجّه الكاميرا نحو صورة `assets/demo-target.png` (على شاشة الحاسوب أو مطبوعة على ورقة/كفر) وسيعمل الفيديو والأزرار فوراً فوق التصميم.
- لتجربة سريعة قبل توليد `targets.mind`، اضغط زر **"معاينة الفيديو والأزرار (بدون كاميرا)"** داخل الصفحة.

## نصائح مهمة للطباعة الحرارية (Sublimation)
- اختر تصاميم ذات **تباين عالٍ وتفاصيل واضحة** (تجنّب المساحات الفارغة بلون واحد أو الأنماط المتكررة المتشابهة) لرفع ثبات التتبع.
- اجعل حجم رمز الـ QR المطبوع على الكفر لا يقل عن `1.8 × 1.8 سم` مع ترك هامش أبيض بسيط حوله لسهولة المسح.
- اختبر أول كفر مطبوع تحت إضاءة الغرفة العادية للتأكد من أن لمعان السطح لا يعيق تتبع الكاميرا.
